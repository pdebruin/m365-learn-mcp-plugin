# Learn Docs

A Microsoft 365 Copilot agent that searches Microsoft Learn documentation, finds code samples, and fetches full articles — grounded in official Microsoft content. The agent is a declarative agent (configuration only, no backend) that connects to the public [Learn MCP Server](https://learn.microsoft.com/api/mcp) via an MCP plugin.

- [investigation.md](investigation.md) — original exploration: rationale, integration layers, build journal, lessons learned
